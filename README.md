# PS Bloghosting

**PS Bloghosting** verwandelt WordPress Multisite in eine leistungsfähige Bloghosting-Plattform mit kostenlosen und kostenpflichtigen Webseiten, verschiedenen Hosting-Stufen und optionalen Premium-Funktionen.

Das Plugin basiert ursprünglich auf **Pro Sites von WPMU DEV** und wurde für **PSOURCE** weiterentwickelt, modernisiert und an aktuelle WordPress-/PHP-Versionen angepasst.

Du kannst damit aus einer normalen Multisite ein eigenes Bloghosting-System aufbauen – inklusive kostenpflichtiger Upgrades, Abonnements, Premium-Plugins, Premium-Themes, Werbefreiheit, Statistiken und zahlreichen weiteren Funktionen.

PS Bloghosting ermöglicht dir unter anderem:

- kostenlose Testzeiträume

- individuelle Preise pro Hosting-Level
- Premium-Plugins

## 💎 Premium-Upgrades

Mit PS Bloghosting kannst du deinen Benutzern verschiedene Hosting-Pakete anbieten.

Ein kostenloses Paket kann beispielsweise grundlegende Funktionen enthalten, während kostenpflichtige Pakete zusätzliche Möglichkeiten freischalten.

Beispiele:

- werbefreie Webseiten

- zusätzliche Plugins
- zusätzliche Themes
- mehr Veröffentlichungsmöglichkeiten

## 💰 Hosting-Pakete verkaufen

Du kannst beliebig viele Hosting-Level erstellen und für jedes Level eigene Preise und Leistungen definieren.

Zum Beispiel:

| Level | Preis | Leistungen |
|---|---:|---|
| Kostenlos | 0 € | Grundfunktionen |
| Basic | 4,99 € / Monat | mehr Speicher, werbefrei |
| Pro | 9,99 € / Monat | Premium-Plugins und Themes |
| Business | 19,99 € / Monat | maximale Funktionen |

Die Anzahl und Struktur der Level bestimmst komplett du selbst.

# 🧩 Module

PS Bloghosting ist modular aufgebaut.

Du musst nicht sämtliche Funktionen aktivieren. Stattdessen kannst du die Module verwenden, die du für dein Netzwerk tatsächlich benötigst.

Je nach Version und Konfiguration stehen unter anderem folgende Module zur Verfügung:

### Werbung

Ermöglicht es, Werbung für bestimmte Hosting-Level zu deaktivieren.

Außerdem können Hosting-Level Benutzern erlauben, Werbung auf weiteren Webseiten zu deaktivieren.

### Bulk Upgrades

Ermöglicht den Verkauf mehrerer Upgrades als Paket.

### BuddyPress-Einschränkungen

Bestimmte BuddyPress-Funktionen können auf ausgewählte Hosting-Level beschränkt werden.

### Veröffentlichungs-Limits

Du kannst festlegen, welche Hosting-Level Beiträge und/oder Seiten veröffentlichen dürfen.

### Pay-to-Blog

Eine Webseite kann vollständig gesperrt werden, bis der Benutzer ein kostenpflichtiges Hosting-Level besitzt.

### Beitrags- und Seiten-Limits

Du kannst festlegen, wie viele Beiträge, Seiten oder andere Inhaltstypen ein bestimmtes Hosting-Level erstellen darf.

### Premium Plugins

Premium-Plugins können gezielt für bestimmte Hosting-Level freigeschaltet werden.

![Premium Plugins](http://web.archive.org/web/20160320133631im_/https://premium.wpmudev.org/wp-content/uploads/2009/01/features-583x373.png)

### Premium Support

Du kannst einen speziellen Support-Bereich für bestimmte Hosting-Level anbieten.

### Premium Themes

Bestimmte Themes können ausschließlich für ausgewählte Hosting-Level verfügbar gemacht werden.

### XML-RPC

XML-RPC kann auf bestimmte Hosting-Level beschränkt werden.

### Ungefiltertes HTML

Die Berechtigung `unfiltered_html` kann gezielt für bestimmte Hosting-Level freigeschaltet werden.

### Upload-Limit

Zusätzlicher Speicherplatz kann für bestimmte Hosting-Level bereitgestellt werden.

# ⚙️ Einrichtung

## 1. Plugin installieren

Installiere **PS Bloghosting** in deiner WordPress-Multisite.

Anschließend aktivierst du das Plugin im Netzwerk unter:

**Netzwerkverwaltung → Plugins**

und aktivierst es **netzwerkweit**.

---

## 2. Hosting-Level erstellen

Nach der Aktivierung legst du zunächst deine Hosting-Level fest.

Du kannst beliebig viele Level erstellen.

Zum Beispiel:

- Kostenlos
- Basic
- Pro
- Business

Für jedes Level kannst du eigene Preise und Funktionen definieren.

![Hosting-Level erstellen](http://web.archive.org/web/20160320133631im_/https://premium.wpmudev.org/wp-content/uploads/2011/10/addnewlevel.png)

---

## 3. Einstellungen konfigurieren

Unter den Einstellungen kannst du PS Bloghosting an deine eigene Plattform anpassen.

Dazu gehören unter anderem:

- Branding
- Namen
- kostenlose Testzeiträume
- E-Mail-Benachrichtigungen
- Zahlungsoptionen
- verschiedene Hosting-Funktionen

![PS Bloghosting Einstellungen](http://web.archive.org/web/20160320133631im_/https://premium.wpmudev.org/wp-content/uploads/2011/10/problogssettings.png)

---

## 4. Module aktivieren

Unter:

**PS Bloghosting → Module / Gateways**

kannst du die benötigten Module und Zahlungsanbieter aktivieren.

Die einzelnen Module besitzen eigene Einstellungen.

![Module](http://web.archive.org/web/20160320133631im_/https://premium.wpmudev.org/wp-content/uploads/2011/10/problogsmeny.png)

---

## 5. Zahlungsanbieter konfigurieren

Anschließend kannst du die gewünschten Zahlungsanbieter konfigurieren.

Je nach verfügbarer Gateway-Unterstützung kannst du beispielsweise PayPal, Stripe oder manuelle Zahlungen verwenden.

![Zahlungsanbieter](http://web.archive.org/web/20160320133631im_/https://premium.wpmudev.org/wp-content/uploads/2011/10/gateways.png)

# 🛒 Upgrade durch Benutzer

Sobald PS Bloghosting eingerichtet ist, können Benutzer ihre eigene Webseite auf ein anderes Hosting-Level upgraden.

Die verfügbaren Hosting-Level werden übersichtlich dargestellt.

Das aktuell verwendete Level wird dabei hervorgehoben.

![Hosting-Level auswählen](http://web.archive.org/web/20160320133631im_/https://premium.wpmudev.org/wp-content/uploads/2011/11/pro-sites-subscription-selection.png)

---

# 🔄 Upgrades und Downgrades

PS Bloghosting berücksichtigt bei Änderungen des Hosting-Levels die bestehende Laufzeit eines Abonnements.

### Upgrade

Beim Upgrade wird der noch vorhandene Zeitraum berücksichtigt und der fällige Betrag entsprechend berechnet.

Das neue Hosting-Level kann dadurch unmittelbar genutzt werden.

### Downgrade

Bei einem Downgrade wird das niedrigere Hosting-Level für den folgenden Abrechnungszeitraum berücksichtigt.

Mit den entsprechenden Modulen kannst du Plugins und Themes gezielt an Hosting-Level koppeln.

| Basic | Einige Premium-Plugins | zusätzliche Themes |
| Pro | Alle freigegebenen Plugins | Premium-Themes |
| Business | vollständiger Zugriff | vollständiger Zugriff |

So kannst du deine Multisite flexibel als echtes Hosting-Angebot betreiben.
